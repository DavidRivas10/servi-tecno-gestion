## Orden recomendado para empezar
1. Abre `index.html`.
2. En Inventario registra tus productos reales.
3. En Configuración ajusta porcentajes o asignaciones si hace falta.
4. Registra aportes de capital en Caja y capital.
5. Comienza a registrar ventas y reparaciones reales.
6. Registra todos los gastos.
7. Revisa Reportes al cierre de la semana.

Los datos se guardan en el navegador mediante localStorage.
